Otwórz folder w Android Studio -> Build > Build APK(s). Wymagany JDK 17 (Android Studio ma wbudowany).
Na telefonie: zainstaluj, Ustawienia > Dostępność > TaxiHelper > włącz. (Android 13+: jeśli zablokowane – Info o aplikacji > ⋮ > Zezwól na ustawienia z ograniczeniami.)

HUAWEI P20 PRO (EMUI): po włączeniu usługi dostępności wejdź w Ustawienia > Bateria > Uruchamianie aplikacji > TaxiHelper,
wyłącz "Zarządzaj automatycznie" i włącz 3 przełączniki. Zablokuj apkę kłódką w widoku ostatnich aplikacji.
Jeśli kafelek przestaje się pojawiać – sprawdź, czy usługa dostępności nadal jest włączona (EMUI potrafi ją wyłączyć).

BUDOWANIE BEZ ANDROID STUDIO: wrzuć cały folder na GitHub (nowe repozytorium) -> zakładka Actions -> Build APK -> Artifacts -> TaxiHelper-apk.
